# Embassy Submission Runbook

## Objective

Package and submit ADEVE Creations supplier documentation to `HarareGSOProcurement@state.gov`, then maintain a weekly opportunity monitoring cadence.

## Submission Package Contents

- Completed company profile
- Capability statement PDF
- Legal registration proof
- Reference list and experience summary
- Compliance declaration (NDAA, local tax, VAT note)
- Completed pre-submission quality checklist

## Steps

1. Validate dossier completeness using `pre-submission-checklist.md`.
2. Update `registration-status.md` with latest NCAGE/SAM/UEI progress.
3. Prepare outbound email using `embassy-cover-email-template.md`.
4. Send package to `HarareGSOProcurement@state.gov`.
5. Log submission activity in `opportunity-log.md` (with status: Submitted Profile).
6. Set reminder to follow up if no response within 10 business days.

## Weekly Operations Cadence

- Review Embassy procurement opportunity sources once per week.
- Add new opportunities to `opportunity-log.md`.
- Update status values (`New`, `Assessing`, `Preparing Response`, `Submitted`, `Closed`).
- Track owner and response deadlines for each opportunity.
