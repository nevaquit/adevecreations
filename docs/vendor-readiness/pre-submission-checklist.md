# Pre-Submission Quality Checklist

Use this checklist before submitting a supplier package to `HarareGSOProcurement@state.gov`.

## Completeness

- [ ] Company profile is fully completed
- [ ] Legal registration proof is attached
- [ ] Capability statement PDF is attached
- [ ] At least three references are included
- [ ] Experience summary covers three or more years

## Accuracy

- [ ] Contact names, emails, and phone numbers are correct
- [ ] Service categories are consistent across all documents
- [ ] Dates and document versions are current

## Compliance

- [ ] NDAA declaration included
- [ ] Local tax compliance statement included
- [ ] VAT zero-rating acknowledgement included

## Final Review

- [ ] Internal owner approved package quality
- [ ] Cover email drafted and reviewed
- [ ] Submission date logged in tracker
