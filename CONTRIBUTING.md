# Contributing Guide

## Workflow

1. Create a feature branch from `main`.
2. Make focused changes with clear commit messages.
3. Run checks locally:
   - `npm run check`
   - `npm run build`
4. Open a pull request and complete the PR checklist.

## Content Governance

- Keep procurement claims factual and verifiable.
- Do not publish legal or tax-sensitive documents with private identifiers.
- Ensure all compliance statements are dated and versioned.
- Update docs and website content together when supplier posture changes.

## Review Expectations

- At least one reviewer approval before merge.
- CI must pass.
- Keep pull requests small and scoped to one concern when possible.
